# Technical Notes

## 1. Biggest Docker Problem

The biggest problem I faced was keeping the task data after stopping and removing the container

I solved this problem by using a Docker named volume called task_data. This volume stores the JSON file outside the container, so the tasks remain available when the container is started again

## 2. Git/GitHub Lesson

The most important lesson I learned is how to use Git and GitHub to manage a project

I learned how to create a repository, track changes, write meaningful commit messages, and push my work to GitHub
